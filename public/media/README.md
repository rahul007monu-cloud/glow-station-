# Video yahan upload karein

| Filename | Kahan chalega |
| --- | --- |
| `hero.mp4` | Hero background (auto-play, muted, loop) **aur** scroll-scrubbed section — scroll karte hi video aage-peeche chalti hai |
| `tour.mp4` | Salon tour loop (optional) |

File na ho to kuch nahi tootta — site photo par chali jaati hai.

## GitHub se upload (phone/laptop, sirf browser)

1. Repo kholo → `public/media` folder
2. **Add file → Upload files**
3. Video ko `hero.mp4` naam do → **Commit changes**
4. 2 minute me site par live

## Video kaisi honi chahiye

- **Format:** MP4 (H.264 + AAC) — sab browsers me chalti hai
- **Length:** 10–20 second (loop ke liye best)
- **Quality:** 1080p kaafi hai; 4K se site slow hoti hai
- **Size:** **20 MB se kam** rakhein (GitHub web upload ki limit 25 MB hai)
- **Sound:** zaroori nahi — muted chalti hai (browser rule)
- **Shot list jo best lagta hai:** shop ka board/entrance → andar walk-in → mirror station →
  stylist kaam karte hue → client ka final look reveal

> 20 MB se badi file ho to WhatsApp par bhej kar compress ki hui file use karein,
> ya "Compress video" app se 1080p/8 Mbps par export karein.
